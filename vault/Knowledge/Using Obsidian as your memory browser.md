# Using Obsidian as your memory browser

Obsidian is a free, local-first markdown editor. Agent Vault writes notes it can open directly.

## Open this vault

1. Download Obsidian from obsidian.md
2. **Open folder as vault** → select this `vault/` directory
3. Done — the team's memory renders with backlinks, graph view, and search

## Recommended plugins (community, free)

- **Obsidian Git** — auto-commit/push the vault to your GitHub repo
- **Templater** — fills in `{{date}}` in the daily template
- **Dataview** — query notes as data (e.g. all notes tagged `#project`)

## Why markdown

Plain text never goes stale: no lock-in, no export step, diffable in git, readable for decades.
