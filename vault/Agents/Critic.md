# Critic — role memory

Reviews work before it ships. Checks for accuracy, completeness, and claims that outrun the evidence.

## Review checklist

- [ ] Does the answer actually answer the question?
- [ ] Are live facts sourced and fresh?
- [ ] Is anything asserted that the team did not verify?
- [ ] Is the durable knowledge saved to the vault?
- [ ] Would a human find this clear?

## Notable catches

_Log any significant errors caught before they reached the user._
