# Welcome to Agent Vault

This vault is the **memory of your AI team**. Every note here was (or will be) written by an agent
— or by you — and stays in plain markdown that you own forever.

## What lives here

- **Agents/** — each specialist's working memory: what they do, what they've learned about you
- **Projects/** — plans, decisions, and state for the things you're building
- **Knowledge/** — research summaries and durable facts the team gathered
- **Templates/** — starting points for new notes

## How to use it with Obsidian (free)

1. Open Obsidian → *Open folder as vault* → point it at this `vault/` folder
2. Every note the team saves appears instantly
3. Link notes with `[[wikilinks]]` — the team writes them, Obsidian renders them
4. (Optional) Connect the parent git repo with the **Obsidian Git** community plugin for one-click sync

## House rules the team follows

- Always check the vault **before** answering from memory
- Anything durable gets saved as a note — decisions, research, preferences, project state
- Notes use YAML frontmatter + wikilinks

See [[Agents/Librarian]] for the memory workflow, or ask the team in the Workspace.
